## آیا Penhoon UI رایگان و متن‌باز است؟

بله. Penhoon UI تحت مجوز GPL-3.0 متن‌باز است. کد منبع آن روی
[GitHub](https://github.com/Arman2122/p-ui) در دسترس است.

## روی چه سیستم‌هایی اجرا می‌شود؟

روی بیشتر توزیع‌های اصلی Linux (Ubuntu، Debian، CentOS/RHEL و مشتقات آن‌ها،
Fedora، Arch، Alpine و موارد دیگر) روی معماری‌های `amd64`، `arm64` و دیگر معماری‌ها.
همچنین به‌صورت یک کانتینر Docker اجرا می‌شود. به [نصب](/docs/guide/installation) مراجعه کنید.

## SQLite یا PostgreSQL؟

SQLite گزینه پیش‌فرض است و برای بیشتر استقرارها مناسب است. PostgreSQL برای
راه‌اندازی‌های بزرگ‌تر از طریق `PUI_DB_TYPE=postgres` و `PUI_DB_DSN` در دسترس است — به
[متغیرهای محیطی](/docs/reference/env-vars) مراجعه کنید.

## کدام اپلیکیشن‌های کلاینت با آن کار می‌کنند؟

هر کلاینت سازگار با Xray — برای مثال v2rayNG، Hiddify و Clash/Mihomo.
لینک اشتراک‌گذاری یا کد QR یک کلاینت را وارد کنید، یا از
[سابسکریپشن](/docs/config/subscription) استفاده کنید.

## نسبت Penhoon UI با 3x-ui و x-ui چیست؟

Penhoon UI یک فورک از [3x-ui](https://github.com/MHSanaei/3x-ui) ساختهٔ MHSanaei است؛
پروژه‌ای که خودش فورکی ارتقایافته از پنل اصلی x-ui به‌شمار می‌رود. در مقایسه با x-ui، از
همین مسیر پشتیبانی گسترده‌تر از پروتکل‌ها، پایداری بهتر، حسابداری ترافیک به‌ازای هر کلاینت
و مدیریت چندنودی به ارث رسیده است. Penhoon UI با تغییرات خودش این مسیر را ادامه می‌دهد و
رابط کاربری‌اش را به دو زبان — انگلیسی و فارسی — ارائه می‌کند.

## چگونه به‌روزرسانی کنم؟

اسکریپت نصب را دوباره اجرا کنید (به‌صورت درجا به‌روزرسانی می‌شود)، یا ایمیج جدید Docker را دریافت کنید.
به [نصب](/docs/guide/installation) و
[صفحه نسخه‌ها](https://github.com/Arman2122/p-ui/releases) مراجعه کنید.

## از کجا می‌توانم کمک بگیرم؟

برای پرسش‌ها و گزارش اشکال‌های مربوط به Penhoon UI، یک ایشو روی
[GitHub](https://github.com/Arman2122/p-ui/issues) باز کنید. برای مشکلات رایج، با
[عیب‌یابی](/docs/help/troubleshooting) شروع کنید. پرسش‌های عمومی دربارهٔ خانوادهٔ x-ui را
می‌توانید در کانال Telegram پروژهٔ بالادستی 3x-ui یعنی [@XrayUI](https://t.me/XrayUI)
نیز مطرح کنید.
