‏Penhoon UI پیکربندی زمان‌اجرای خود را از متغیرهای محیطی `PUI_*` می‌خواند. در نصب
اسکریپتی، نصب‌کننده آن‌ها را در فایل محیطی سرویس که systemd می‌خواند، یعنی
`/etc/default/p-ui`، می‌نویسد. مقادیر پیش‌فرض منطقی هستند — فقط آنچه را که نیاز به تغییر
دارید تنظیم کنید، سپس ری‌استارت کنید: `systemctl restart p-ui`.

## پایگاه‌داده

| Variable                 | Default     | Description                                                          |
| ------------------------ | ----------- | -------------------------------------------------------------------- |
| `PUI_DB_DSN`             | —           | **الزامی.** رشته‌ی اتصال PostgreSQL، مثلاً `postgres://pui:password@127.0.0.1:5432/pui?sslmode=disable`. |
| `PUI_DB_MAX_OPEN_CONNS`  | —           | حداکثر اتصالات باز در استخر PostgreSQL.                         |
| `PUI_DB_MAX_IDLE_CONNS`  | —           | حداکثر اتصالات بی‌کار در استخر PostgreSQL.                         |

تنها بک‌اند موجود PostgreSQL است. اگر `PUI_DB_DSN` تنظیم نشده یا نامعتبر باشد، پنل به‌جای
بازگشت به هر گزینه‌ی دیگری هنگام راه‌اندازی خارج می‌شود — به
[پایگاه‌داده](/docs/reference/database) مراجعه کنید.

## پنل

| Variable                 | Default | Description                                                              |
| ------------------------ | ------- | ------------------------------------------------------------------------ |
| `PUI_PORT`               | —       | بازنویسی پورت پنل (۱ تا ۶۵۵۳۵). بر تنظیم ذخیره‌شده اولویت دارد. |
| `PUI_INIT_WEB_BASE_PATH` | `/`     | مسیر پایه‌ی وب اولیه در **نخستین** اجرا (مثلاً `/panel`).               |
| `PUI_ENABLE_FAIL2BAN`    | `true`  | فعال‌سازی اعمالِ محدودیت IP مبتنی بر Fail2ban.                              |
| `PUI_SKIP_HSTS`          | `false` | رد کردن هدر HSTS — وقتی TLS توسط یک پروکسی معکوس خاتمه می‌یابد، `true` تنظیم کنید. |

## لاگ‌گیری و باینری‌ها

| Variable         | Default          | Description                                                 |
| ---------------- | ---------------- | ----------------------------------------------------------- |
| `PUI_LOG_LEVEL`  | `info`           | `debug`، `info`، `notice`، `warning`، یا `error`.           |
| `PUI_DEBUG`      | `false`          | حالت دیباگ (سطح لاگ را به `debug` وادار می‌کند).                   |
| `PUI_LOG_FOLDER` | `/var/log/p-ui`  | پوشه‌ی خروجی لاگ.                                       |
| `PUI_BIN_FOLDER` | `bin`            | پوشه‌ی باینری Xray-core و فایل‌های geosite/geoip.    |

## حافظه و پروفایلینگ

پنل با استفاده از `GOGC` و آزادسازی‌های دوره‌ای، مصرف حافظه را پایین نگه می‌دارد.
این‌ها تنظیمات پیشرفته‌ای هستند — مگر اینکه در حال تنظیم دقیق یک میزبان با منابع
محدود باشید، آن‌ها را تنظیم‌نشده رها کنید.

| Variable                      | Default | Description                                                       |
| ----------------------------- | ------- | ----------------------------------------------------------------- |
| `PUI_GOGC`                    | —       | درصد هدف GC در Go؛ کمتر = RAM کمتر، CPU اندکی بیشتر.     |
| `PUI_MEMORY_RELEASE_INTERVAL` | —       | فاصله‌ی زمانی فراخوانی‌های `FreeOSMemory` بر حسب دقیقه؛ مقدار `0` آن را غیرفعال می‌کند.               |
| `PUI_MEMORY_LIMIT`            | —       | محدودیت نرم حافظه‌ی Go بر حسب **MiB**.                                  |
| `GOMEMLIMIT`                  | —       | محدودیت نرم با نحو Go (مثلاً `400MiB`)؛ بر مورد بالا اولویت دارد.|
| `PUI_PPROF`                   | `false` | در دسترس قرار دادن پروفایلینگ pprof روی `127.0.0.1:6060`.                       |

## Xray

## پایشگر سلامت تونل

نگهبان اختیاری: یک URL را پروب می‌کند (به‌صورت اختیاری **از طریق** یک ورودی محلی
‏Xray) و پس از خرابی‌های مکرر، Xray را ری‌استارت می‌کند. هر ری‌استارت همه‌ی
کلاینت‌های متصل را قطع می‌کند، پس آن را آگاهانه فعال کنید.

| Variable                      | Default                                      | Description                                                       |
| ----------------------------- | -------------------------------------------- | ----------------------------------------------------------------- |
| `PUI_TUNNEL_HEALTH_MONITOR`   | `false`                                      | فعال‌سازی پایشگر.                                               |
| `PUI_TUNNEL_HEALTH_PROXY`     | —                                            | پروکسی‌ای که پروب از طریق آن ارسال می‌شود، مثلاً `socks5://127.0.0.1:1080`. خالی = فقط اتصال میزبان را بررسی می‌کند. |
| `PUI_TUNNEL_HEALTH_URL`       | `https://www.cloudflare.com/cdn-cgi/trace`   | URLی که پروب می‌شود.                                                     |
| `PUI_TUNNEL_HEALTH_INTERVAL`  | `30s`                                        | فاصله‌ی زمانی بین پروب‌ها.                                         |
| `PUI_TUNNEL_HEALTH_TIMEOUT`   | `10s`                                        | مهلت زمانی هر پروب.                                              |
| `PUI_TUNNEL_HEALTH_FAILURES`  | `3`                                          | تعداد خرابی‌های متوالی پیش از یک ری‌استارت.                          |
| `PUI_TUNNEL_HEALTH_COOLDOWN`  | `5m`                                         | حداقل تأخیر بین ری‌استارت‌ها.                                 |

## نصب بدون نظارت

| Variable             | Description                                                                                  |
| -------------------- | -------------------------------------------------------------------------------------------- |
| `PUI_NONINTERACTIVE` | روی `1` تنظیم کنید (یا بدون TTY اجرا کنید) تا نصب بدون هیچ پرسشی انجام شود؛ اطلاعات احراز هویتِ تولیدشده در `/etc/p-ui/install-result.env` نوشته می‌شوند. نگاه کنید به [نصب](/docs/guide/installation#unattended--cloud-init). |
