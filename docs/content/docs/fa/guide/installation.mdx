‏Penhoon UI روی **Ubuntu نسخه‌های ۲۲.۰۴، ۲۴.۰۴ و ۲۶.۰۴** و **Debian نسخهٔ ۱۲ به بالا**
اجرا می‌شود، روی معماری‌های `amd64`، `arm64`، `armv7` و `s390x`. به یک میزبان systemd که
با `apt` مدیریت می‌شود نیاز دارد و داده‌هایش را در **PostgreSQL** نگه می‌دارد.

<Callout type="warn">
  نصب‌کنندهٔ اسکریپتی را به‌صورت **root** (یا با `sudo`) اجرا کنید. این اسکریپت یک
  سرویس نصب می‌کند، دستور مدیریتی `p-ui` را راه‌اندازی می‌کند و پنل را در زمان
  بوت فعال می‌سازد.
</Callout>

<Tabs items={['Script', 'Manual']}>

<Tab value="Script">

اسکریپت رسمی مسیر توصیه‌شده است. این اسکریپت در طول نصب، PostgreSQL را راه‌اندازی می‌کند،
یک نام کاربری، رمز عبور و مسیر دسترسی (مسیر پایهٔ وب) **تصادفی** می‌سازد، سرویس را نصب
می‌کند و دستور مدیریتی `p-ui` را در دسترس قرار می‌دهد.

```bash title="latest stable"
bash <(curl -Ls https://raw.githubusercontent.com/Arman2122/p-ui/main/install.sh)
```

برای نصب یک **نسخهٔ مشخص**، تگ آن را در انتها اضافه کنید:

```bash title="pinned version"
bash <(curl -Ls https://raw.githubusercontent.com/Arman2122/p-ui/main/install.sh) v3.4.0
```

برای نصب نسخهٔ **dev** غلتان (آخرین پیش‌انتشار به‌ازای هر کامیت از شاخهٔ `main`
— نه یک نسخهٔ پایدار) عبارت `dev-latest` را پاس دهید:

```bash title="rolling dev build"
bash <(curl -Ls https://raw.githubusercontent.com/Arman2122/p-ui/main/install.sh) dev-latest
```

پس از پایان نصب، مشخصات ورود چاپ‌شده را یادداشت کنید و دستور `p-ui` را اجرا کنید تا
[منوی مدیریت](/docs/guide/update-uninstall#the-p-ui-management-menu) باز شود، سپس
به [نخستین ورود](/docs/guide/first-login) ادامه دهید.

</Tab>

<Tab value="Manual">

برای کاربران پیشرفته، یک آرشیو انتشار متناسب با معماری خود را از
[صفحهٔ releases](https://github.com/Arman2122/p-ui/releases) دانلود کنید، آن را
استخراج کنید، یک پایگاه‌دادهٔ PostgreSQL در دسترس را از طریق `PUI_DB_DSN` معرفی کنید و
باینری را به‌عنوان یک سرویس systemd اجرا کنید. اسکریپت نصب دقیقاً همین مراحل را خودکار
می‌کند، بنابراین مگر اینکه دلیل خاصی برای نصب دستی داشته باشید، روش اسکریپتی ترجیح داده
می‌شود.

</Tab>

## پایگاه‌داده

‏Penhoon UI همه‌چیز را در PostgreSQL ذخیره می‌کند؛ این تنها بک‌اند پشتیبانی‌شده است.
نصب‌کننده دو مسیر پیش رویتان می‌گذارد:

- **نصب محلی PostgreSQL** (توصیه‌شده) — بستهٔ توزیع را نصب می‌کند و یک کاربر و
  پایگاه‌دادهٔ اختصاصی برای پنل می‌سازد.
- **استفاده از سرور موجود** — یک DSN وارد می‌کنید و نصب‌کننده پنل را به آن وصل می‌کند.

در هر دو حالت، رشتهٔ اتصال با نام `PUI_DB_DSN` در `/etc/default/p-ui` نوشته می‌شود و
تنظیم آن **الزامی** است: بدون آن پنل بالا نمی‌آید. نگاه کنید به
[پایگاه‌داده](/docs/reference/database).

## نصب خودکار / cloud-init

نصب‌کننده برای خودکارسازی به‌صورت **غیرتعاملی** نیز اجرا می‌شود.
`PUI_NONINTERACTIVE=1` را تنظیم کنید (یا بدون TTY اجرا کنید) تا نصب به‌صورت
سرتاسری و بدون هیچ پرسشی انجام شود، مشخصات تصادفی تولید کند و آن‌ها را در
`/etc/p-ui/install-result.env` بنویسد:

```bash
PUI_NONINTERACTIVE=1 bash <(curl -Ls https://raw.githubusercontent.com/Arman2122/p-ui/main/install.sh)
```

در حالت غیرتعاملی، اگر `PUI_DB_DSN` از قبل در محیط یا در `/etc/default/p-ui` تنظیم شده
باشد از همان سرور استفاده می‌شود؛ در غیر این صورت PostgreSQL به‌صورت محلی نصب می‌گردد.

دایرکتوری [`deploy/`](https://github.com/Arman2122/p-ui/tree/main/deploy) در مخزن
یک user-data آمادهٔ **cloud-init** برای نصب‌های خودکار روی هر ابری (Hetzner، AWS،
DigitalOcean، Vultr، GCP، Azure، Oracle) دارد.
