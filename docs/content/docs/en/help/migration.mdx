## Between servers

Moving to a new server is a database move:

<Steps>

<Step>
### Back up the old server

Take a database dump from the panel's **Back Up** button (or with `pg_dump`) and
copy your certificates. See
[Backup & restore](/docs/operations/backup-restore).
</Step>

<Step>
### Install Penhoon UI on the new server

Use a compatible version, and let the installer set up PostgreSQL there. See
[Installation](/docs/guide/installation).
</Step>

<Step>
### Restore the database

Import the dump from the panel (or `pg_restore` it), restore certificates, and
restart the panel. Update any IP/domain-specific settings.
</Step>

</Steps>

## Between Penhoon UI versions

Upgrading is usually just re-running the installer or `p-ui update` — the panel
migrates its own schema. Across **major** versions, read the
[release notes](https://github.com/Arman2122/p-ui/releases) first and take a
backup.

## From the original x-ui

Importing an older x-ui panel's database directly into Penhoon UI is **not
supported** — the schemas differ. Install Penhoon UI fresh and recreate
inbounds/clients, exporting share links from the old panel as you go.

<Callout type="warn">
  Always take a backup before any migration, and keep the old server running
  until you've verified the new one.
</Callout>
