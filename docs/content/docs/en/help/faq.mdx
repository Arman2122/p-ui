## Is Penhoon UI free and open source?

Yes. Penhoon UI is open source under the GPL-3.0 license. The source is on
[GitHub](https://github.com/Arman2122/p-ui).

## What systems does it run on?

Most major Linux distributions (Ubuntu, Debian, CentOS/RHEL and derivatives,
Fedora, Arch, Alpine, and more) across `amd64`, `arm64`, and other architectures.
It also runs as a Docker container. See [Installation](/docs/guide/installation).

## SQLite or PostgreSQL?

SQLite is the default and is fine for most deployments. PostgreSQL is available
for larger setups via `PUI_DB_TYPE=postgres` and `PUI_DB_DSN` — see the
[environment variables](/docs/reference/env-vars).

## Which client apps work with it?

Any Xray-compatible client — for example v2rayNG, Hiddify, and Clash/Mihomo.
Import a client's share link or QR code, or use a
[subscription](/docs/config/subscription).

## How does Penhoon UI relate to 3x-ui and x-ui?

Penhoon UI is a fork of [3x-ui](https://github.com/MHSanaei/3x-ui) by MHSanaei, which
is itself an enhanced fork of the original x-ui panel. Compared with x-ui, that lineage
brings broader protocol support, improved stability, per-client traffic accounting, and
multi-node management. Penhoon UI builds on it with its own changes, and ships its
interface in two languages — English and Farsi.

## How do I update?

Re-run the install script (it updates in place), or pull the new Docker image.
See [Installation](/docs/guide/installation) and the
[releases page](https://github.com/Arman2122/p-ui/releases).

## Where can I get help?

Open an issue on [GitHub](https://github.com/Arman2122/p-ui/issues) — that is the
main place to reach the Penhoon UI maintainers. For common problems, start with
[Troubleshooting](/docs/help/troubleshooting). Behaviour inherited from upstream
is also discussed in the 3x-ui community Telegram channel,
[@XrayUI](https://t.me/XrayUI).
