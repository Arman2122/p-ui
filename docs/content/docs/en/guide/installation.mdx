Penhoon UI runs on **Ubuntu 22.04, 24.04 and 26.04** and **Debian 12 or newer**, on
`amd64`, `arm64`, `armv7` and `s390x`. It expects a systemd host managed with
`apt`, and stores its data in **PostgreSQL**.

<Callout type="warn">
  Run the script installer as **root** (or with `sudo`). It installs a service,
  sets up the `p-ui` management command, and enables the panel on boot.
</Callout>

<Tabs items={['Script', 'Manual']}>

<Tab value="Script">

The official script is the recommended path. During installation it sets up
PostgreSQL, generates a **random** username, password, and access (web base)
path, installs the service, and installs the `p-ui` management command.

```bash title="latest stable"
bash <(curl -Ls https://raw.githubusercontent.com/Arman2122/p-ui/main/install.sh)
```

Install a **specific version** by appending its tag:

```bash title="pinned version"
bash <(curl -Ls https://raw.githubusercontent.com/Arman2122/p-ui/main/install.sh) v3.4.0
```

Install the rolling **dev** build (the latest per-commit pre-release from `main`
— not a stable release) by passing `dev-latest`:

```bash title="rolling dev build"
bash <(curl -Ls https://raw.githubusercontent.com/Arman2122/p-ui/main/install.sh) dev-latest
```

When it finishes, note the printed login details and run `p-ui` to open the
[management menu](/docs/guide/update-uninstall#the-p-ui-management-menu), then
continue to [First login](/docs/guide/first-login).

</Tab>

<Tab value="Manual">

For advanced users, download a release archive for your architecture from the
[releases page](https://github.com/Arman2122/p-ui/releases), extract it, provide
a reachable PostgreSQL database via `PUI_DB_DSN`, and run the binary as a systemd
service. The install script automates exactly these steps, so it's preferred
unless you have a specific reason to install by hand.

</Tab>

</Tabs>

## The database

Penhoon UI stores everything in PostgreSQL — it is the only supported backend.
The installer offers two routes:

- **Install PostgreSQL locally** (recommended) — it installs the distro package
  and creates a dedicated role and database for the panel.
- **Use an existing server** — paste a DSN and the installer wires the panel to
  it.

Either way the connection string lands in `/etc/default/p-ui` as `PUI_DB_DSN`,
which is **required**: without it the panel refuses to start. See
[Database](/docs/reference/database).

## Unattended / cloud-init

The installer also runs **non-interactively** for automation. Set
`PUI_NONINTERACTIVE=1` (or run with no TTY) and it installs end-to-end with zero
prompts, generating random credentials and writing them to
`/etc/p-ui/install-result.env`:

```bash
PUI_NONINTERACTIVE=1 bash <(curl -Ls https://raw.githubusercontent.com/Arman2122/p-ui/main/install.sh)
```

Non-interactively it installs PostgreSQL locally unless `PUI_DB_DSN` is already
set in the environment or in `/etc/default/p-ui`, in which case it reuses that
server.

The repo's [`deploy/`](https://github.com/Arman2122/p-ui/tree/main/deploy)
directory has ready-made **cloud-init** user-data for unattended installs on any
cloud (Hetzner, AWS, DigitalOcean, Vultr, GCP, Azure, Oracle).
