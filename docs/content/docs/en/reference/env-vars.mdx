Penhoon UI reads its runtime configuration from `PUI_*` environment variables. On a
script install the installer writes them to the service environment file that
systemd loads, `/etc/default/p-ui`. Defaults are sensible — set only what you need
to change, then restart: `systemctl restart p-ui`.

## Database

| Variable                 | Default     | Description                                                          |
| ------------------------ | ----------- | -------------------------------------------------------------------- |
| `PUI_DB_DSN`             | —           | **Required.** PostgreSQL connection string, e.g. `postgres://pui:password@127.0.0.1:5432/pui?sslmode=disable`. |
| `PUI_DB_MAX_OPEN_CONNS`  | —           | Max open connections in the PostgreSQL pool.                         |
| `PUI_DB_MAX_IDLE_CONNS`  | —           | Max idle connections in the PostgreSQL pool.                         |

PostgreSQL is the only backend. With `PUI_DB_DSN` unset or unparseable the panel
exits at startup instead of falling back to anything — see
[Database](/docs/reference/database).

## Panel

| Variable                 | Default | Description                                                              |
| ------------------------ | ------- | ------------------------------------------------------------------------ |
| `PUI_PORT`               | —       | Override the panel port (1–65535). Takes precedence over the stored setting. |
| `PUI_INIT_WEB_BASE_PATH` | `/`     | Initial web base path on **first** launch (e.g. `/panel`).               |
| `PUI_ENABLE_FAIL2BAN`    | `true`  | Enable Fail2ban-based IP-limit enforcement.                              |
| `PUI_SKIP_HSTS`          | `false` | Skip the HSTS header — set `true` when TLS is terminated by a reverse proxy. |

## Logging & binaries

| Variable         | Default          | Description                                                 |
| ---------------- | ---------------- | ----------------------------------------------------------- |
| `PUI_LOG_LEVEL`  | `info`           | `debug`, `info`, `notice`, `warning`, or `error`.           |
| `PUI_DEBUG`      | `false`          | Debug mode (forces log level to `debug`).                   |
| `PUI_LOG_FOLDER` | `/var/log/p-ui`  | Log output directory.                                       |
| `PUI_BIN_FOLDER` | `bin`            | Folder for the Xray-core binary and geosite/geoip files.    |

## Memory & profiling

The panel keeps memory low via `GOGC` and periodic releases. These are advanced
knobs — leave them unset unless you're tuning a constrained host.

| Variable                      | Default | Description                                                       |
| ----------------------------- | ------- | ----------------------------------------------------------------- |
| `PUI_GOGC`                    | —       | Go GC target percentage; lower = less RAM, slightly more CPU.     |
| `PUI_MEMORY_RELEASE_INTERVAL` | —       | Minutes between `FreeOSMemory` calls; `0` disables.               |
| `PUI_MEMORY_LIMIT`            | —       | Go soft memory limit in **MiB**.                                  |
| `GOMEMLIMIT`                  | —       | Go-syntax soft limit (e.g. `400MiB`); takes precedence over above.|
| `PUI_PPROF`                   | `false` | Expose pprof profiling on `127.0.0.1:6060`.                       |

## Xray

| Variable                 | Default | Description           |
| ------------------------ | ------- | --------------------- |
| `XRAY_VMESS_AEAD_FORCED` | `false` | Force VMess AEAD.     |

## Tunnel health monitor

Optional watchdog: it probes a URL (optionally **through** a local Xray inbound)
and restarts Xray after repeated failures. A restart drops all connected
clients, so enable it deliberately.

| Variable                      | Default                                      | Description                                                       |
| ----------------------------- | -------------------------------------------- | ----------------------------------------------------------------- |
| `PUI_TUNNEL_HEALTH_MONITOR`   | `false`                                      | Enable the monitor.                                               |
| `PUI_TUNNEL_HEALTH_PROXY`     | —                                            | Proxy to send the probe through, e.g. `socks5://127.0.0.1:1080`. Empty = only checks host connectivity. |
| `PUI_TUNNEL_HEALTH_URL`       | `https://www.cloudflare.com/cdn-cgi/trace`   | URL to probe.                                                     |
| `PUI_TUNNEL_HEALTH_INTERVAL`  | `30s`                                        | Interval between probes.                                         |
| `PUI_TUNNEL_HEALTH_TIMEOUT`   | `10s`                                        | Per-probe timeout.                                               |
| `PUI_TUNNEL_HEALTH_FAILURES`  | `3`                                          | Consecutive failures before a restart.                          |
| `PUI_TUNNEL_HEALTH_COOLDOWN`  | `5m`                                         | Minimum delay between restarts.                                 |

## Unattended install

| Variable             | Description                                                                                  |
| -------------------- | -------------------------------------------------------------------------------------------- |
| `PUI_NONINTERACTIVE` | Set to `1` (or run with no TTY) to install with zero prompts; generated credentials are written to `/etc/p-ui/install-result.env`. See [Installation](/docs/guide/installation#unattended--cloud-init). |
